Two different failure modes

Why a "plausible" patch can still be wrong

OVERFITTING

The patch games the tests

Hard-codes a test value, or changes behaviour on inputs that already worked.

if numbers == [1, 2]: return 1.5
UNDERSPECIFIED

The docstring never says what average([]) should return. Several fixes are equally valid.

Accepting one silently makes a design decision for the developer.

What exists, and the gap we target

Exists

Patch correctness prediction

PATCH-SIM, ODS, APPT, Invalidator, Crex, Prism, RePaCA. Binary labels: correct or overfitting. No notion of ambiguity.

Exists

Ambiguity from disagreement

SpecFix (ASE 2025), ClarifyGPT. Cluster sampled programs to detect ambiguous task descriptions, but only for code generation.

Our contribution

Why do candidates disagree?

Learn to separate "some patches are wrong" from "the spec is silent", in program repair, without a developer reference fix.

Clustering alone cannot make this split: both causes produce more than one behaviour cluster.

Research question

For every patch that passes the tests, predict one of three verdicts

ACCEPT

Correct

Fixes the bug and preserves intended behaviour.

REJECT

Overfitting

Passes the visible tests but breaks intended behaviour.

ABSTAIN AND ASK

Spec-ambiguous

Valid under the spec, which is silent on some input. Report that input to the developer.

Goal: fewer wrong patches accepted than "tests pass", without throwing away good fixes.

5 plausible patches, run on ~100 inputs, form 4 behaviour clusters.

OVERFITTING

c4 agrees with the others on only 10% of ordinary inputs. It is broken, not ambiguous.

AMBIGUOUS

c0 to c3 agree everywhere except average([]), where the docstring is silent. Ask the developer.

Deep learning model

Three branches, one calibrated verdict

Code branch

UniXcoder encodes buggy code, diff and docstring. Frozen first, top 4 layers fine-tuned if time allows.

Evidence branch

MLP over 30 features: behaviour preservation, fail-to-pass, cluster statistics, static smells.

Cluster branch (novel)

2-layer Transformer over behaviour clusters, no positional encoding. The patch's own cluster is the query.

Gated fusion, then 3-way softmax with temperature scaling
L = LCE + λ · LSupCon   (λ ≈ 0.1, contrast patches of the same bug)

Accept only above a threshold set for a 5% false-accept rate. Abstain when P(ambiguous) is highest.
